Écris un module llmlang complet nommé `M` avec une part :

    clamp(x: Int, lo: Int, hi: Int) -> Int

Elle borne `x` dans l'intervalle [lo, hi] : renvoie lo si x est en dessous, hi si x
est au-dessus, x sinon. Contrats :

    requires lo <= hi
    ensures result >= lo and result <= hi

Le module doit passer `lll check` : toutes les obligations déchargées.
