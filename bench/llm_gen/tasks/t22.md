Use the parametric ADT `Option[a]` (import `std/option.lll`) as the honest
replacement for a sentinel default. Write `flag(b: Bool) -> Int` (1/0) and
`safe_head(xs: List[Int]) -> Option[Int]` returning `None` for `[]` and
`Some(h)` for `h :: t`. `main()` prints `flag(get_or(safe_head(7 :: []), 0) == 7)`
(presence) then `flag(is_none(safe_head([])))` (absence) — every printed 1 is a
fact proven statically by Z3 and observed at runtime.
