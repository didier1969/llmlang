Bind a foreign Rust enum across the FFI boundary (by-name marshalling). Using
the crate at `tests/fixtures/ffi_enum` (declare it with
`depends ffi_enum "1.0.0" from "<relative-path>"`), declare a local
`type Sign = Neg | Zero | Pos` and an `effect Cmp` with two extern ops:
`sign_of(Int) -> Sign` bound to `ffi_enum::sign_of` as
`(i64) -> enum ffi_enum::Sign [ Neg -> Neg, Zero -> Zero, Pos -> Pos ]`, and
`sign_to_int(Sign) -> Int` bound to `ffi_enum::sign_to_int` with the same
by-name arm list on its argument. `main()` computes `sign_of(0 - 7)`, round-trips
it back through `sign_to_int`, and prints the result.
