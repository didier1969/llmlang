Define a typeclass `Eq[a]` with a method `eq(a, a) -> Bool` and a
`law reflexive(x: a): eq(x, x)`. Provide `instance Eq[Int]` where `eq` is
integer equality. Write a generic part `same(x: a, y: a) -> Bool given Eq[a]`
that yields `eq(x, y)` — verified ONCE, abstractly. `main()` prints 1 when
`same(1, 1)` holds, else 0.
