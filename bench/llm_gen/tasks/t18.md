Model an interchangeable EFFECTFUL resource with a typeclass over an effect
(typeclass-over-effect). Declare nullary tags `Console` and `Silent`, a
phantom-parameterised handle `type Handle[h] = Handle(Int)`, and a class
`Sink[h]` with `open(h, Int) -> Handle[h] via IO` and
`write(Handle[h], Int) -> Int via IO`. Instance `Sink[Console]` writes via
`IO.print`; instance `Sink[Silent]` returns the value unprinted. Write ONE
generic `run(w: h, x: Int) -> Int via IO given Sink[h]` that opens a handle from
the witness `w` and writes `x` through it — monomorphized over both sinks.
`main()` runs it once with `Console` (x = 7) and yields it once with `Silent`
(x = 9).
